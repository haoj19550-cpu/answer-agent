Redis 缓存击穿通常发生在哪一种情况下？

A大量 key 在同一时间集中过期，请求全部打到数据库
B某个热点 key 失效瞬间，并发请求同时打到数据库
C查询一个数据库中根本不存在的数据，缓存永远命中不了
DRedis 内存不足触发淘汰策略，大量 key 被移除

知识解析

缓存击穿的关键词是「热点 key」和「失效瞬间」：一个高并发访问的热点数据突然过期，所有请求同时穿透到数据库。A 描述的是雪崩，C 描述的是穿透。

原文依据：「缓存击穿是热点 key 失效瞬间并发请求打到数据库」
